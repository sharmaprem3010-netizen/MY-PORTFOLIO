# MY-PORTFOLIO
Source code for my personal portfolio website, built to highlight my accuracy and organization services while pursuing my BCA. BY PREM SHARMA

## Run locally

This portfolio now uses a small Node.js JSON backend instead of browser-only storage, so the same content can load on every device.

1. Install Node.js if it is not already on your machine.
2. Open this folder in a terminal.
3. Run `node server.js`.
4. Open `http://localhost:3000` in your browser.

## Shared data

The editable portfolio content is stored in [portfolio-data.json](portfolio-data.json). The website reads and writes that file through the API in [server.js](server.js).
