# Prem Sharma — Software Developer Portfolio

An editorial, anime and manga-inspired portfolio website showcasing software development projects, technical skills, design philosophy, and exploratory work.

## ✨ Features

- **Editorial & Manga-Inspired Aesthetic**: High-contrast typography pairing Space Grotesk and Playfair Display with alternating light/dark paper aesthetic.
- **Storytelling Narrative Chapters**: Hero title lockup, character study, 3-panel manga origin journey, and 8-step iterative engineering loop.
- **Interactive Project Showcase**: Featured builds with interactive media, category tags, live preview/repository links, and detailed slide-over drawers.
- **Vocabulary & Skills**: Interactive cloud of technical skills and learning nodes with popover descriptions.
- **Terminal Note**: Thought loop and philosophy interactive code terminal.
- **Recruiter Mode**: Instant toggle to an executive recruiter dashboard with structured credentials, project breakdown, and direct contact avenues.
- **Responsive & Accessible**: Smooth keyboard navigation (`Esc` drawer dismissal), mobile-ready layout, custom cursor, and reading depth progress tracking.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sharmaprem3010-netizen/MY-PORTFOLIO.git

# Navigate to the project directory
cd MY-PORTFOLIO

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be available at `http://localhost:3000` (or the port specified by Vite).

### Building for Production

```bash
npm run build
```
